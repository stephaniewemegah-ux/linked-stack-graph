# Linked Stack & Graph (Java)

Data Structures, Assignment 2: Wemegah Stephanie Sefak (4420250902)

- `LinkedStack.java`: integer stack built from linked nodes (push, pop, peek, isEmpty, size, clear, display)
- `Graph.java`: undirected graph as an adjacency list (addEdge, removeEdge, hasEdge, degree, bfs, dfs, hasPath, display)
- `Main.java`: demo with normal and error cases

## Run
    javac *.java
    java Main

Sample output is in `output.txt`.
